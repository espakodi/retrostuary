Retrostuary — Repositorio

Skin estilo Windows 95 para Kodi 21 Omega, basada en Estuary (phil65 y Piers, equipo de Kodi). Mod de RubénSDFA1laberot — EspaKodi.

Instalar desde el repositorio (recomendado)

  1. En Kodi: Ajustes → Interfaz → Explorador de archivos → Añadir fuente.
  2. En <Ninguno> pega esta dirección exacta:

    https://espakodi.github.io/retrostuary/
  3. Como nombre pon retrostuary (o lo que quieras) y acepta.
  4. Ve a Ajustes → Add-ons → Explorador de add-ons (el icono de paquete) → Instalar desde archivo zip.
    Si aparece un aviso de seguridad: Ajustes → Sistema → Add-ons → activa Orígenes desconocidos.
  5. Selecciona la fuente retrostuary y el fichero repository.retrostuary-1.0.0.zip.
  6. Cuando salga la notificación de add-on instalado, entra en Instalar desde repositorio → Retrostuary Repository → Aspecto → Retrostuary → Instalar.

Ya tenías la skin instalada a mano

Kodi marca las instalaciones manuales y no las actualiza solas; para que empiece a recibir actualizaciones tienes que desinstalar el ZIP antiguo y repetir los pasos de arriba. Al instalar desde el repositorio, Kodi sustituye la copia anterior sin preguntarte nada.

Instalar la skin sin el repositorio

Descarga el zip y usa Add-ons → icono de paquete → Instalar desde archivo zip. Esta via no recibe actualizaciones.

  • skin.retrostuary-1.5.4.zip

Zip para instalar el repositorio

  • repository.retrostuary-1.0.0.zip
